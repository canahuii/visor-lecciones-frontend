Leccion 1: Array no densos, o dispersos

para mas informacion visita: array no densos o dispersos>array densos

java script permite crear array e inicializar componentes no contiguos.

ejemplo de codigo:

                    let vec = [];   
                    vec[5] = 100;
                    vec[10] = 200;

                    document.write('atributo length: ' + vec.length +  "< br>")
                    for(let i = 0; i < vec.length  ; i++ )
                    {
                        document.write(vec[i] + "< br>")
                    }
