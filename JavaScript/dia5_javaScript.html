leccion 2 del dia: uso de for

el uso de for si lo incluimos aqui ya que la sintaxis si es un poco diferente de la de java.
esta estructura se usa cuando se sabe de ante mano cuantas veces de debe de repetir el ciclo
el bucle se puede detener en cualquien punto de la iteracion usando la palabra break 

                    Sintaxis:
                    for (<  Inicialización  > ; <   Condición   > ; <   Incremento o Decremento >)
                    {
                        < Instrucciones >
                    }
                
                    sintaxis que usaremos en este ejemplo:
                    for(let i= 0; i <= 10 ; i++)
                    {
                        document.write( "< span >"+ i + "< /span >" )
                    }
