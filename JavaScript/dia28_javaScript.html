Leccion 1 del dia: ARray: instruccion delete

Para mas informacion visita: Array: instruccion delete

Delete es una instruccion que elimina un elemento del vector, no modifica el tamanño (length) cuando usas delete el vector se vuelve un vector disperso

delete vect[3]

ejemplo

problema

Crear un vector de 10 elementos y almacenar valores aleatorios en el mismo. Luego borrar los elementos de las posiciones pares e imprimir el vector antes y después de borrar las componentes, inclusive tratar de acceder a las componentes que acabamos de borrar.
