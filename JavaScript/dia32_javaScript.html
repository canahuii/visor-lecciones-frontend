Leccion 1 de dia: metodo slice

Para mas informacion visita: Array: metodo slice

El metodo slice retorna un trozo del vector:
la sintaxis es:
vec.slice(2,4);

el primer paramtro del slice indica desde que elemento se deve de devolver y el desgundo paramtro hasta que elemento se retornará. no se toma e cuanta el elemento de la posicion del segundo parametro al evolver el valor: 

                    let vec = [10, 20, 30, 40, 50, 60];
                    document.write('Vector original< br>');
                    for (let f = 0; f < vec.length; f++) {
                        document.write(vec[f] + '-');
                    }
                    document.write('< br>');
                    let vec2 = vec.slice(1, 4);
                    document.write('Vector resultante de la llamada a slice< br>');
                    for (let f = 0; f < vec2.length; f++) {
                        document.write(vec2[f] + '-');
                    }

Usar un solo parametro

si en el metodo slice solo colocas un parametro, te devolvera un vector desde la posicion del paramtro hast el final:

let vec=[10,20,30,40,50,60];
let vec2=vec.slice(2); // vec2 almacena [30,40,50,60]

tambien podemos ingresarle parametros negativos:
let vec=[10,20,30,40,50,60];
let vec2=vec.slice(1,-1); // vec2 almacena [20,30,40,50]

Leccion 2 del dia: Metodo join

para mas informacion visita: Metodo join

el metodo join concatena todos los elementos de un array en un solo String.
al metodo join es necesario darle como parametro el o los caracteres que usara como separacion entre elemento y elemento del array.
puedes llamar al metodo join sin parametro, y usara su valor por defecto, la coma ","

let vec=[10,20,30,40,50];
let cadena=vec.join();
document.write(cadena); //10,20,30,40,50 

                    let vec = [10, 20, 30, 40, 50];
                    let cadena = vec.join('-');
                    document.write(cadena);

Leccion 3 del dia: uso del metodo concat

para mas informacion visita: Array metodo concat

el metodo concat compia el vector originar y le agrega los datos que le estas pasando como parametro y te devuelve un vector nuevo, esto no afecta al vector originar puedes pasarle datos separados vec1.concat(1,2,3,4) o puedes pasarle otro vector vec1.concat(vec2);

ejemplo de codigo

            let vec1 = [10, 20, 30, 40];
                let vec2 = [100, 200, 300, 400];
                let vecsuma = vec1.concat(vec2);
                document.write('Primer vector:');
                document.write(vec1.join() + '< br>');
                document.write('Segundo vector:');
                document.write(vec2.join() + '< br>');
                document.write('vectores concatenados:');
                document.write(vecsuma.join() + '< br>');
