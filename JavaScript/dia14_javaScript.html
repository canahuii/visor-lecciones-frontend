leccion 1 del dia: evento onLoad

para mas informacion visita: uso de onLoad

el evento onLoad se ejecuta al finalizar la carga de la pagina en el navegador.
es decir cuando la pagina ya ha cargado todos los formularios, imagenes, etc..
uno de los posibles usos puede ser colocar el foco en una caja de texto especifica.

onLoad se declara en la parte de body llamando a la funciona activar:
sintaxis
< body onload="activar()"> < /body>

leccion 2 del dia: objeto window

para mas informacion visita: objeto window

representa la ventana del navegador, es un objeto global y tiene los siguientes metodos:

alert
un mensaje de alerta con un mensaje
prompt
muestra un dialogo para la entrada de un valor de tipo string
confirm
muestra un dialogo de confirmacion con los botones confirmar y cancelar
open y close
abre o cierra una ventana del navegador. podemos definir el tamaño de la ventana, su contenido etc...
[Variable=][window.]open(URL, nombre, propiedades)
si queremos tener acceso a ella desla venta donde la creamos debemos asignarle una variable y si no solo simvoamos el metodo.
las propiedades son una lista, separada por comas, de algunos de los siguientes elementos
  • toolbar[=yes/no]
  • location[=yes/no]
  • directories[=yes/no]
  • status[=yes/no]
  • menubar[=yes/no]
  • scrollbars[=yes/no]
  • resizable[=yes/no]
  • width[=pixels]
  • height[=pixels]
