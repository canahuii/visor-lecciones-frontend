leccion 1 del dia: definicion de un estilo en base al contexto

Supongamos que queremos que cuando disponemos un texto encerrado por el elemento strong dentro de un párrafo el color del mismo sea verde. Pero si el elemento strong está contenida por el elemento h1 el color debe ser rojo, luego la sintaxis del problema es:
deberiamos de declararlo asi:
p strong{ color:#0000ff;}
h1 strong{color:#ff0000;}

este es un parafo encerrado dentro de una etiqueta p y esto esta dentro de un strong dentro de una etiqueta p

esto solo esta encerrado dentro de un h1 y esto entan en un strong dentro de un h1

se puede ser un poco mas preciso con las declaraciones:

si delcaramos:

div h1 em {color:yellow;}

Con esto estamos diciendo que se debe pintar de color amarillo el texto contenido por el elemento em siempre y cuando esté contenida en un elemento h1 y esta a su vez dentro de un div.

este texto esta dendro de un "div", dentro de un "h1", dentro de un "em"
