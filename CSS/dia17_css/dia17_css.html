leccion 1 del dia: Propiedad float aplicada a una imagen

para mas informacion visita: Float aplicado a una imagen

la propiedad float permite sacar un objeto del flujo de la pagina, puede tener estos tres valores: 

                    left
                    right
                    none
cuando usamos esta propiedad podemos hacer que el texto envuelva a la imagen.

Leccion 2 del dia: propiedad float aplicada a otros elementos

para mas informacion visita : float aplica a otros elementos
se puede flotar cualquier elemento html, pero afecta que es lo que lo reodea si es texto, una etiqueta o un contenedor

ejemplo

Aqui me pongo a cantar
Al compas de la viguela;
que el hombre que lo devela
Una pena extraordinaria,
como la ave solitaria
con el cantar se consuela.

Pido a los santos de cielo
que ayuden mi pensamiento.
Les pido este momento
Que voy a cantar esta historia,
Me refresquen la memoria
y aclaren mi entendimiento.

Vengan, santos milagrosos,
Vengan todos en mi ayuda,
Que la lengua se me añuda
Y se me turba la vista.
Pido a mi Dios que me asista
En una ocasión tan ruda.

leccion 3 del dia: aplicaremos la propiedad clear

para mas informacion visita: uso de clear

se emplea en elementos que ya se les haya asignado el valor float clear no permite que el elemento flote en un dado caso que se haya definido dicho elemento con esa propiedad anteriormente:
los valores que podemos asignarle a clear son:
both
left
right
none
