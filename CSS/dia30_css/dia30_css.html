Leccion 3 del dia: flex aplicado a los items

para mas informacion visita: flex aplicada a los items

la propiedad flex es elformato resumido de flex-grow, flex-shrink, flex-basis

el orden de los valores en caso de querer aplicar los tres es: flex: valor flex-grom valor flex-shrink valor flex-basis
ejemplo:

flex: 1 0 60%;
estamos cargado 1 en flex-grow, 0 en flex-shrink y 60% en flex-basis 

                    Hay posibilidades de inicializar la propiedad flex con menos de tres valores y que los otros queden con valores por defecto:
                            
                    flex: 1 2;   /* flex-basis queda con su valor por defecto */
                    flex: 1 20%; /* flex-shrink queda con su valor por defecto */
                    flex: none;  /* se almacenan los valores 0 0 auto*/
                    flex: auto; /* Especificamos los valores por defecto de cada propiedad */
