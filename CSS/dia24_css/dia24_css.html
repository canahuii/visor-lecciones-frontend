leccion 1 del dia: nth-of-type, nth-last-of-type, first-of-type y last-of-type

para mas infomacion visita: Pseudo-clases: nth-of-type, nth-last-of-type, first-of-type y last-of-type

:nth-of-type(n)
Qué hace: Selecciona el hijo número n pero solo contando elementos del mismo tipo.
:nth-last-of-type(n)
Qué hace: Igual que :nth-of-type, pero cuenta desde el final.
:first-of-type
Qué hace: Selecciona el primer hijo de un tipo específico dentro del padre.
:last-of-type
Qué hace: Selecciona el último hijo de un tipo específico dentro del padre.

leccion 2 del dia: only-child y only-of-type

para mas informacion visita: only-child y only-of-type

la clase only-child se aplica cuando en dicho nivel hay un solo elemento.

ahora la clase only-of-type se aplica cuando en dicho nivel hay un solo elemento de ese tipo (no importa cuantos otros elementos hay de otro tipo en el mismo)
