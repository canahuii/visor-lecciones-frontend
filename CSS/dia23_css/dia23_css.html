leccion 1 del dia: first-child , last-child

para mas informacio visita: first-child, last-child

la pseudoclase first-child nos permite seleccionar el primer elemento hijo de otro elemento padre y de manera similar la pseudoclase last-child selecciona el ultimo elemento hijo. 

                    ol li:first-child {
                    color:green;
                    }

                    ol li:last-child {
                    color:red;
                    }

  • opcion 2
  • opcion 3
  • opcion 4

leccion 2 del dia: nth-child y nth-last-child

para mas unformacion visita: nth-child y nth-last-child

selecciona uno o mas valores que le pasemos como parametro esta pseudoclase
pasando lo valores odd (impar) y even (par) 

                    tr:nth-child(odd) {
                    background-color:red;
                    }
