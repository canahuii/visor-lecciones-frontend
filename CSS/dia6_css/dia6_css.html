mas propiedades en: propiedades de padding

padding

significa almohadilla y o que hace es sumar espacios entre el contenid del elemento (por ejemplo dentro del elemento párrafo el texto propiamente dicho es el contenido) y el borde (recordar propiedad border)

Podemos configurar los 4 en caso que tengan el mismo valor accediendo a la propiedad: padding:
o se puede configurar de manera independiente cada uno: 
                        padding-top
                        padding-right
                        padding-bottom
                        padding-left
