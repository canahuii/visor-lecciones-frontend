leccion 1 del dia: Selector universal *

si necesitas mas informacion puedes visitar: selector universal

si queremos inicializar las propiedades de todos los elementos de html puedes utilizar el selector universal *
ejemplo: 

                * {
                    margin:0;
                    padding:0;
                    color:#ff0000;
                }
con el selector universal le indicamos que todos los elementos tendas esas mismas caracteristicas.

leccion 2 del dia. pseudoclases

para mayor infromacion puedes visitar: PseudoClases

pseudoclases: son clases especiales, se refiere a algunos estados de elementos de html pricipalmente se usan con < a >
la base de la sintaxis es:

a:pseudoclase {
propiedad: valor;
}

Para el elemento HTML tenemos 4 pseudoclases fundamentales: 

                link - Enlace sin ingresar
                visited - Enlace presionado
                hover - Enlace que tiene la flecha del mouse encima
                active - Es la que tiene foco en ese momento (pruebe de tocar la tecla tab)
            
                Es importante hacer notar que el orden en que definimos las pseudoclases es fundamental para su funcionamiento (debe respetarse el orden: link-visited-hover-active)

ejemplo

Google
Yahoo
Bing

leccion 2 del dia: elimnar el subrayado de un link

-par mayor informacion visita: eliminacion del subrayado de un link

para eliminar el subrayado de un link < a > usaremos pseudoclases

para ello se utiliza el codido: 

                    a:link {
                         text-decoration:none;
                        }

                    a:visited {
                        text-decoration:none;
                        }
este teexto se escribio en una etiqueta h6, usando pseudoclases para hacerlo dinamico
