leccion del dia: como cambiar de cursor

disponemos de una propiedad llamada cursor, con el cual podemos hacer que el cursor cambie de aspecto cuando se coloca sobre un elemento dentro de la pagina. 

                Los valores que podemos asignarle a esta propiedad cursor son:

                    crosshair → Muestra una cruz (+), útil en editores gráficos o mapas.
                    default → El cursor por defecto del sistema (generalmente una flecha).
                    pointer → Una mano señalando, comúnmente usada en enlaces.
                    move → Un cursor con flechas en todas direcciones, indica que el elemento se puede mover.
                    e-resize → Flecha hacia la derecha (este), indica que se puede redimensionar horizontalmente.
                    ne-resize → Flecha hacia arriba a la derecha (noreste).
                    nw-resize → Flecha hacia arriba a la izquierda (noroeste).
                    n-resize → Flecha hacia arriba (norte).
                    se-resize → Flecha hacia abajo a la derecha (sureste).
                    sw-resize → Flecha hacia abajo a la izquierda (suroeste).
                    s-resize → Flecha hacia abajo (sur).
                    w-resize → Flecha hacia la izquierda (oeste).
                    text → Un cursor en forma de “I” (barra vertical), usado en áreas de texto.
                    wait → Un reloj de arena o círculo girando, indica que hay que esperar.
                    help → Un signo de interrogación, indica ayuda disponible.
                    auto → El navegador decide automáticamente el cursor más apropiado según el contexto.
