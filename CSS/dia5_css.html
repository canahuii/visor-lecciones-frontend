leccion 1 del dia: definicion de estilos por medio de clases

En muchas situaciones una regla de estilo puede ser igual para un conjunto de elementos HTML, en esos casos conviene plantear una regla de estilo con un nombre genérico que posteriormente se puede aplicar a varios elementos de HTML.

Para el planteo de una regla de estilo por medio de una clase creamos un nombre de clase y le antecedemos el caracter punto: 

                    .resaltado
                    {
                        color:#000000;
                        background-color:#ffff00;
                        font-style:italic;
                    }
Luego para asignar dicha regla a un elemento HTML definimos la propiedad class al elemento que necesitamos fijarle este estilo:

< h1 class="resaltado">Este elemento h1 aparece con la clase resaltado< /h1>

esta es una etiqueta h3 al que se le aplico la regla de resaltadopor medio de clases

leccion 2 del dia: definicion de estilos por medio de ID

la diferencia entre la definicion por clases es que por demio de id solo se le puede agregar estilo a un solo elemento.
ejemplo de codigo: 

                    #cabecera 
                    {
                        font-family:Times New Roman;
                        font-size:30px;
                        text-align:center;
                        color:#0000ff;
                        background-color:#bbbbbb;
                    }

esta es una etiqueta h3 que se aplico estilo por medio de id

leccion 3 del dia: propiedades relacionadas con el borde de un elemento

todo elemento en html tiene un borde, los elementos mas importantes son:

  1. border-width
  2. border-style
  3. border-color

estos son algunos estilos de borde que puedes usar
  1. none ( sin borde )
  2. hidden ( invisible )
  3. dotted ( borde de puntos )
  4. dashed ( borde de guines )
  5. solid ( linea continua )
  6. double ( dos lineas paralelas )
  7. groove ( borde con efecto 3d undido )
  8. ridge ( borde con efecto 3d elevado )
  9. inset ( hace que el borde parezca incrustado en la pagina )
  10. outset ( hace que el borde parezca sobre salir )
