Este titulo se modifico con css

al titulo se le dio ese diseño usando:
style = " aqui van los moficadores "
color: aquiva el color que deseas colocar
background - color : color deseado
el codigo completo para darle el estilo fue: style = " color: red; background-color: yellow"

cuando definimos estilos directamente en html, solo se aplica
a la equiqueta que le diste los moficadores, por lo tanto es necesario hacer ese proceso cada vez que quieras dar esilo.

este titulo se hizo modicando al h1 en el head

en este caso se agrego:
< style > h1 {color: white; background-color: black;
font-family: times new roman;
font-size: 30px;
font-style: italic;
font-weight: bold;
}

en la etiqueta head para modificar todas las etiquetas h1, y no manualmente uno por uno.

se hizo lo mismo con la etiqueta h2

y lo mismo con la etiqueta h3
