para mas informacion visita la pagina: dimension de un objeto

para configurar las dimensiones de un objeto contamos con:

width
e ancho del objeto
height
el alto del objeto.
otras cuatro propiedades relacionadas con el alto y el ancho de un elemento html son:
  • min-width ( representa el ancho minimo que puede tomar el objeto )
  • max-width ( fija el ancho maximo que puede tener un elemnto )
  • min-height ( representa la altura minima que puede adoptar el objeto )
  • max-height ( representa la altura maxima que puede adoptar el objeto )

Leccion dos del dia: unidades de medida (px, rem, em, cm, mm etc...)

                Disponemos de las siguientes unidades de medida:

                    px (pixeles) 
                    rem (tamaño de la fuente respecto al elemento raíz del documento)
                    em (altura de la fuente por defecto)
                    ex (altura de la letra x minúscula) 
                    in (pulgadas) 
                    cm (centímetros) 
                    mm (milímetros) 
                    pt (puntos, 1 punto es lo mismo que 1/72 pulgadas) 
                    pc (picas, 1 pc es lo mismo que 12 puntos) 
                    % (porcentaje)

                    Unidades con longitudes relativas
                    De todas las medidas enunciadas en un principio las unidades con longitudes relativas más utilizadas son:

                    1. rem
                    2. em
                    3. %
