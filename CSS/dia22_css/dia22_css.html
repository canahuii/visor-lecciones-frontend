leccion 1 del dia: selector de hermano adyacente y hermano general

para mas informacion visita: selector de hermanos

selector de hermano adyacente
permite seleccionar un elemento html que viene inmediatamente despues del otro elemento html. los dos deben de tener el mismo elemento padre
selector de hermano general
permite seleccionar todos los hermanos y no solo uno como en el caso del hermano adyacente
