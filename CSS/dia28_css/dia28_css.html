Leccion 1 del dia: flex wrap aplicada al contenedor

Para mas informacion visita: flex wrap aplicada al contenedor

flex wrap esto hace que los items siempre esten en el eje principal en una misma linea idependientemente de la cantidad de items que sipongamos.

podemos hacer que el contenedor muestre items en varias lineas cuando no entran en una misma fila disponiendo la propiedad wrap,
algunos de los valor que puedes usar son:

  1. nowrap
  2. wrap
  3. wrap-reverse

Leccion 2 del dia: ALign content aplicada al contenedor

Para mas informacion visita: align-content aplicada al contenedor

la propiedad align-content solo es aplicable cuando disponemos de un flex box con varias lineas, es decir que le allamos colocado el valor wrap al flex-wrap

lod valores posibles de la propiedad align conten son:

  1. stretch
  2. flex-start
  3. flex-end
  4. center
  5. space-between
  6. space-around
