leccion 3 del dia, propiedades relacionadas con el texto

color del texto

para definir el color podemos usar tres valores exadecimas:
color:#ff0000; Si queremos rojo puro:
color:#00ff00 Si queremos verde puro:
color:#0000ff si queremos azul puro

Luego si queremos amarillo debemos mezclar el rojo y el verde: color:#ffff00

Otra forma de indicar el color, si tenemos los valores en decimal, es por medio de la siguiente sintaxis:
color:rgb(255,0,0);

alinear texto

usando la propiedad text-align podemos darle alguno de estos cuatro valores
left
right
center
justify

decoracion de texto

las propiedades que podemos usar son:

none (nunguno)

underline (subrayado)

overline (linea superior)

line-through (tachado)
