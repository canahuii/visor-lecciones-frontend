leccion 1 de dia: uso de FORM

para mayor informacion y mas claridad visita: uso de form

un form permite que el usuario agrege datos en un form y estos sean evnviados al servidor

html no agrega los datos al servidor, de esa tarea se encargan otros lenguajes: (PHP, ASP, ASP.Net, JSP,NodeJS etc.)

primero hay que abrir el FORM donde es necesario iniciar dos propiedades: accion y method por ejemplo:
< form action="registrardatos.php" method="post">< /form>
la propiedad accion se inicializa con el nombre de la pagina que contiene el programa que procesara los datos en el servidor. por temas de aprendizaje todos los formularios se inicializaran con el accion "/registrarDatos.php".

propiedad method este metodo solo puede almacenar dos valores post / get
Normalmente un formulario se envía mediante post (los datos se envían con el cuerpo del formulario) En caso de utilizar get los datos se envían en la cabecera de la petición de la página, utilizando el método get estamos limitados en la cantidad de datos a enviar, no asi con el método post.

ahora vesmos el cuadro de texto:

Ingrese su nombre:
< input type="text" name="nombre" size="20">

El elemento input permite definir un cuadro de texto, y le agregamos la porpiedad text.
el elemento name se debe inicializar con el nombre del cuadro del texto, nos sirve para recuperar los datos luego.
por ultimo inicializamos el elemento size con un valor ejemplo "20" esto limitaria la cantidad de caracateres que e usuario puede ver en el cuadro a la vez

por utimo veamos el codigo:

< input type="submit" value="enviar">

cuando poner type = "submit" lo que hace es crear un boton, y con value colocas cual es texto que se vera dentro del boton
