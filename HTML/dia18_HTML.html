Leccion 2 del dia: Envio de datos mediante e-mail

para mas informacion visita: Formulario- envio de datos mediante e-mail

se puede enviar la infromacion pormedio de un email, enves de enviarlo hacia el servido mediante lenguaje php, este es la sintaxis para iniciar el form:
< form action="mailto:pizzasya@gmail.com" method="post" enctype="text/plain">
tomar en cuenta que no se puede enviar archivos adjuntos.

si quieres que el email tenga un titulo debes de inicializar un subjecct, ejemplo:
< form action="mailto:pedrohernandez99@gmail.com?subject=PEdido de reparacion" method="post" enctype="text/plain">
la desbentaja es que si no tiene configurada tu computadora con un email predeterminado esto no va a funcionar.
