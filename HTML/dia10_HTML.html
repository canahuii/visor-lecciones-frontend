Leccion 1 del dia: Formulatio (INPUT)

Para mas informacion visita: uso de Input

Este elemento nos permite crear botones y cuadros de texto. y mas cosas que veremos en un momento

Actualmente cuando iniciamos algunos elementos los hacermos asi:
< form action="registrarDatos.php" method="post">< /form> se inicializa con action y method

< input type="text" name="nombre" size="20"> iniclaizamos una caja de testo usando type, nmae, size

< input type="password" name="clave" size="15"> pasa una contraseña usamos type, name y size

< input type="submit" value="Enviar"> inicalizamos un boton con type = submit value (el valor que va denro del boton)

< input type="reset" value="borrar"> un boton para borrar todos los datos en las cajas de texto y password. Se inicializa con type= reset y value (valor dentro del boton)

LEccion 2 del dia: Formulario (TEXTAREA)

es como un cuadro de texto pero este contien varias lineas no solo una.
para declarar un textarea es asi:
< textarea name="comentario" id="comentario" rows="5" cols="40">< /textarea>
no se usa input, rows se usa para decirle cuantas filas van a ser visible, cols se usa para indicar cuantas columnas seran visible, esto (rows, cols) no limita el cuadro a esa cantidad de caracteres, solo afecta a la parte visual
