Leccion 1 del dia, input(hidden)

para mas informacion visita: < input type="hidden"> este tipo de control se denomina control oculto. Este control nomuestra nada en el formulario. su utilidad es guardar un dato oculto que luego se pueda rescatar y nviar a un servidor

codigo

                < form action="enviar.php" method="post" enctype="multipart/form-data">
                        < input type="hidden" value="10:20" name="hora">
                        ingrese su nombre < br>
                        < input type="text" name="nombre" size="30"> < br>
                        suba una foto < br>
                        < input type="file" name="foto">
                        < br>
                        < input type="submit">
                        < input type="reset">        
                < /form>

ejemplo

ingrese su nombre

suba una foto

como puedes observar el input hidden no aparece en el formulario, permanece oculto
