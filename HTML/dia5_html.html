leccion 1 del dia: listas ordenadas

se utiliza la marca < ol > ( order list ) para crear la lista ordenada y se usa la etiqueta < li > ( list item )para agregarle los items
se utilizo el siguiente codigo 

                < ol >
                    < li>Rodriguez Pablo< /li>
                    < li>Gonzalez Raul< /li>
                    < li>Lopez Hector< /li>
                < /ol >

resultado

  1. Rodriguez pablo
  2. gonzales Raul
  3. Lopez Hector

leccion 2 del dia: listas no ordenadas

una lista ordenada tiene numeros en cada elemento en cambio la lista no ordenada no tiene esos numeros.
se utliza la etiqueta < ul > ( unorder list ) para crear la lista y la etiqueta < li > ( list item ) 

                < ul>
                    < li>C< /li>
                    < li>C++< /li>
                    < li>Java< /li>
                    < li>C#< /li>
                < /ul>

resultado

  • c
  • c++
  • java
  • c#

leccion 3 del dia: lista de definiciones

se utiliza para asociar un termino y la definicion del mismo
se utiliza la etiqueta < dl > ( definition list)
ponemos en pares lo siguientes terminos < dt > (definition term ) y < dd > ( defition description )

se usara el siguiente codigo: 

                < dl>
                    < dt>C++< /dt>
                    < dd>
                        Es un lenguaje de programación, diseñado a mediados de 
                        los años 1980, por Bjarne Stroustrup, como extensión del lenguaje 
                        de programación C.
                    < /dd>
                    < dt>Java< /dt>
                    < dd>
                        Es un lenguaje de programación orientado a objetos desarrollado 
                        por Sun Microsystems a principios de los 90.< /dd>
                    < dt>JavaScript< /dt>
                    < dd>
                        Es un lenguaje interpretado, es decir, que no requiere compilación, 
                        utilizado principalmente en páginas web, con una sintaxis semejante a la 
                        del lenguaje C.
                    < /dd>
                < /dl>

resultado

c++
es un lenguaje de programcion diseñado a mediados de los años 1980
java
es un lenguaje de programacion orientado a objetos desarrollado por sun Microsystems
JavaScript
es un lenguaje interpretado, es decir no requiere compiladores utilizado principalmente en paginas web
